Implementation Brief

LCT Experience Upgrade

日期：2026-06-06 · 分支：codex/lct-experience-upgrade-20260606

LCT 本轮体验升级已经把三个容易误解的用户界面问题收进可测试合同：HTML 顶部不再把 quorum 黑话当作主信息，输入改写边界写进 Skill/README，自选模型路径和主席贡献说明都有独立 opt-in surface 与 provenance。默认运行路径保持兼容；新增能力只在明确触发时生效。

这轮解决了什么

报告首屏

HTML 顶部从「Quorum 状态」改成「成员模型」。新 run 读取 metadata.quorum.effective_stage1_members，legacy run 只在缺少 quorum metadata 时 fallback 到 config.members。

输入边界

默认 raw original input。只有明确要求真实意图拆解、架构视角、fact pack、最新资料或来源时，外层 Agent 才能进入 structured by Agent。

自选模型

新增 --selected-members / --selected-chairman。agent-assisted 自选路径归一化到 4 并写 provenance；原生 --members 保持精确语义。

贡献说明

--chairman-contribution-map 默认关闭。启用后 Stage 3 写 stage3/contribution_map.json，HTML 从 blocks 确定性渲染来源说明。

关键实现

HTML summary card

src/llm_council_for_trae/html_export.py 的 summary card 改为「成员模型」卡片。新逻辑优先使用有效 Stage 1 成员，并在 quorum metadata 存在但有效成员为空时显示 暂无有效成员记录。

对应提交：9f1a097 feat: simplify LCT report summary and input policy docs

Input policy docs

README.md、canonical Skill 和 .trae Skill 增加 raw / structured / negative trigger matrix，明确 operator envelope 不得写入 _lct_question.md。

对应提交：9f1a097 feat: simplify LCT report summary and input policy docs

Selected model normalization

normalize_user_model_selection(...) 处理用户自选模型：少于 4 个补足，超过 4 个裁剪，正好 4 个保留用户顺序；并写入 manifest.metadata.model_selection。

对应提交：57d411a feat: add explicit selected-model normalization

Chairman contribution map

Stage 3 只在 enabled 时写 sidecar；validate 只在 enabled 时检查结构、成员引用和 consensus 成员数；HTML 不调模型、不按自然段猜来源。

对应提交：5fa99e2 feat: add gated chairman contribution map

测试证据

本轮按 TDD 推进，先写红灯测试，再分阶段实现。阶段验证已覆盖 HTML、Skill、原生成员兼容、自选归一化、provenance、contribution map flag、validate 和 HTML blocks 渲染。

PYTHONPATH=src python3 -m compileall src
git diff --check

截至 5fa99e2 后，全量 make test 通过 243 个 unittest，输出末尾包含既有 fixture 预期的 degraded_ok。最终 PR 前仍会重新执行完整门禁，并在 live runtime 可用时补 live run 和 validate。

兼容性边界

  • --default-models 不变。
  • 原生 --members / --chairman 不变，不补足、不裁剪。
  • profile 和 subagent 路径不走 selected normalization。
  • --chairman-contribution-map 默认关闭；legacy run 缺 sidecar 不失败。
  • contribution map validate 只验证结构和引用合法性，不声称验证真实贡献程度。

剩余风险

contribution map 依赖主席按要求输出结构化 JSON。validate 能拦结构错误，但不能证明主席归因绝对正确。live runtime 的最终证据仍取决于当前 traecli 状态；PR 前和 merge 后 v16 会重新验证。
