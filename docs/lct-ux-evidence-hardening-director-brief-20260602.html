本轮没有做模型稳定性大评测，而是把默认使用路径的输入、搜索、subagent 和 HTML 阅读体验压到更诚实、更可复盘。

结论

  • HTML 报告开头的输入提示词默认折叠，最终答案回到第一阅读面。
  • search_enabled 被拆成 search_allowed 与 search_used，不再暗示允许搜索等于实际搜索。
  • provider 持久化真实 tool_calls，HTML 有可靠证据源。
  • Skill 增加 raw / structured 输入模式，并要求 root index 写明 Input mode。
  • subagent profile 降级为 legacy / experimental，保留历史校验价值，不再是日常主路径。

静态 --default-models 仍可能因为 GLM-5.1 缺席而失败。本轮没有伪装成已完成 roster 重定标。
